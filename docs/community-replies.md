# 댓글로 시작하는 협업과 답변 예시

제안에 관심이 있다면 해당 이슈에 댓글을 남겨주세요. 바로 역할을 확정하지 않아도 괜찮습니다. 먼저 질문하거나, 짧게 사용해보고 의견을 보태는 것으로 시작할 수 있습니다.

## 학우의 참여 댓글

아래 예시에서 자신의 상황에 맞는 내용을 바꿔 사용하세요. 역할과 가능한 시간은 서로 이야기하기 위한 정보이며, 참여 조건이 아닙니다.

### 함께 작업하고 싶을 때

```text
관심 있습니다! 화면 개발을 도울 수 있어요.
주로 주말에 작업할 수 있습니다.
현재 진행한 내용과 먼저 함께할 작업을 알려주실 수 있을까요?
```

### 아직 경험이 적거나 역할을 정하지 못했을 때

```text
관심 있는 주제라 함께해보고 싶습니다.
아직 경험이 많지는 않지만 사용해보고 의견을 남기거나 문서를 정리할 수 있어요.
작은 작업부터 참여할 수 있을까요?
```

### 질문부터 하고 싶을 때

```text
제안 잘 읽었습니다. 어떤 사용 상황을 생각하고 계신지 궁금해요.
예시를 조금 더 알려주시면 제가 도울 수 있는 부분을 함께 찾아보고 싶습니다.
```

## 관리자 답변 템플릿

실제로 확인하거나 처리한 상태에 맞는 예시를 선택하고, 대괄호로 표시한 내용은 바꿔주세요. 이 문서는 복사해서 사용하는 예시이며 댓글이 자동으로 등록되지는 않습니다.

### 조직 참여 요청을 확인했을 때

```text
안녕하세요. 참여 요청 확인했습니다!
남겨주신 소개와 관심 분야를 읽었습니다. 조직 초대가 진행되면 이 이슈에서 안내드리겠습니다.

그동안 관심 있는 저장소를 둘러보시거나, 다른 학우의 협업 제안에 댓글로 이야기 나눠주세요.
아직 함께할 프로젝트를 정하지 않으셔도 괜찮습니다.
```

### 조직 초대를 실제로 보낸 뒤

```text
안녕하세요. 이 이슈를 작성하신 GitHub 계정으로 inha-oss 조직 초대를 보냈습니다.
GitHub 알림이나 이메일에서 초대를 확인하고 수락해주세요.

초대를 찾기 어렵거나 수락에 문제가 있으면 이 이슈에 댓글을 남겨주세요.
함께해주셔서 반갑습니다!
```

### 추가 확인이 필요할 때

```text
안녕하세요. 참여 요청 확인했습니다.
진행을 위해 [추가로 확인할 내용]을 확인하고 싶습니다.

개인정보나 증빙 자료는 공개 댓글에 올리지 말아주세요.
공개하기 어려운 내용이라면 먼저 말씀해주시면 확인 방법을 안내드리겠습니다.
```

### 협업 제안을 확인했을 때

```text
제안 감사합니다! [함께하고 싶은 일]을 함께할 학우를 찾고 계시는군요.
관심 있는 학우는 이 이슈 댓글에 질문이나 도울 수 있는 부분을 남겨주세요.

제안자님은 동료와 논의하면서 처음 함께할 작은 작업을 정해주시면 좋겠습니다.
이미 작업 중인 저장소가 있다면 링크를 남겨주세요. 조직 내 저장소가 필요하다면 필요한 용도와 공개 범위를 이 이슈에서 함께 이야기해주세요.
```

### 동료가 모여 작업을 시작할 때

```text
함께할 분들과 첫 작업이 정해졌네요!
앞으로 작업할 저장소는 [저장소 링크]입니다.

저장소 README에 프로젝트 소개와 참여 방법을 남기고, 할 일과 논의는 해당 저장소의 이슈로 이어가주세요.
이 제안은 [추가 동료 모집 중 / 모집 완료] 상태입니다.
```

모집 완료 여부와 이슈를 닫을 시점은 제안자와 확인해주세요. 정해지지 않은 역할, 일정, 지원 여부를 답변에서 약속하지 않도록 합니다.
